# Metared — Dashboard de Sostenibilidad Universitaria

Herramienta de consulta para funcionarios de sostenibilidad de las universidades que hacen parte de la Red Iberoamericana de Universidades (MetaRed). Permite explorar indicadores y buenas prácticas de sostenibilidad institucional, e incluye un agente basado en LLM con capacidad de análisis de datos sobre la información cargada.

## Contenido

- `app.py` — aplicación Flask
- `data/` — datos de la encuesta de indicadores
- `templates/`, `assets/`, `index.html` — interfaz del dashboard
- `analisis_datos.md`, `buenas_practicas.xlsx`, `encuesta.xlsx` — insumos de análisis
- `dashboard_previo.md`, `estilo_referencia.md` — notas de diseño del dashboard

## Stack

Python + Flask, Pandas para procesamiento de datos, desplegado en Railway.
